CARA MEMASANG WEBSITE ULANG TAHUN AYAH

1. Ekstrak file ZIP.
2. Buka folder website_ulang_tahun_ayah.
3. Pastikan ada:
   - index.html
   - folder assets
4. Di dalam assets harus ada:
   - foto1.jpeg
   - foto2.jpeg
   - foto3.jpeg
   - foto4.jpeg
   - lagu.mp3
5. Untuk tes, klik dua kali index.html. Website akan terbuka di browser.
6. Untuk GitHub Pages:
   a. Buat/buka repository GitHub.
   b. Upload index.html dan folder assets beserta isinya.
   c. Masuk Settings > Pages.
   d. Pilih Deploy from a branch.
   e. Pilih branch main dan folder / (root).
   f. Save.
7. Tunggu beberapa saat, lalu buka alamat GitHub Pages yang diberikan GitHub.

MENGGANTI NAMA AYAH / TEKS:
Buka index.html dengan VS Code/Notepad.
Cari teks "Selamat" atau teks surat, lalu ubah sesuai kebutuhan.

MENGGANTI FOTO:
Cukup ganti file di folder assets dengan nama file yang sama.
